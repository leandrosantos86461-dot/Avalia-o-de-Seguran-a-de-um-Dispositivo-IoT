# Analise do firmware didatico

A imagem foi gerada para o laboratorio e nao foi
extraida de hardware fisico.

A integridade e identificada por SHA-256.

A leitura das strings permite encontrar:
- debug_enabled=true
- wifi_ssid=LAB_SIMULADO
- mqtt_host=127.0.0.1

Todos os dados sao artificiais.

Em firmware real seria necessario investigar
particoes, armazenamento, protecao de credenciais
e mecanismos de atualizacao.
